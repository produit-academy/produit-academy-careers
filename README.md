# Produit Academy - Careers Portal

This is the dedicated careers portal for prospective teachers and staff to apply for open positions at Produit Academy.

## Features
- **Job Listings**: Viewing open positions within the academy.
- **Application Flow**: Submitting resumes and details for job applications.

## Tech Stack
- Next.js
- React

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
